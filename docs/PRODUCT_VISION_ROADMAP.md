# Product Vision And Roadmap

Aligna is evolving from an AI artifact generator into an AI-assisted project management platform.

## New value proposition

Aligna helps teams:

- turn briefing into backlog
- refine requirements with less ambiguity
- generate QA and architecture with less rework
- require human approval for critical artifacts
- keep project execution visible and governed

## Suggested positioning

**Aligna is an AI-assisted project management platform that reduces ambiguity, accelerates alignment, and improves delivery quality before and during execution.**

## What already exists

- project creation
- backlog generation by agent
- story-level requirements refinement
- story-level QA generation
- architecture gate before implementation
- AI provider governance and fallback
- project board
- documentation export

## What is missing for a full project-management feel

- roadmap and milestones
- due dates and dependencies
- clear owners for each task
- blockers and impediments
- comments, mentions, and activity history
- executive project health
- configurable workflows per project

## Roadmap by phase

### Phase 1. Execution control

Goal: make the board useful every day.

Deliverables:

- task owners
- start and end dates
- blockers and impediments
- checklist visibility
- comments and mentions
- activity history

### Phase 2. Planning and management

Goal: add project and roadmap visibility.

Deliverables:

- milestones
- roadmap by period
- task dependencies
- capacity by person or team
- visual prioritization

### Phase 3. Governance and intelligence

Goal: turn the platform into a decision hub.

Deliverables:

- human approval for critical artifacts
- decision audit trail
- executive reports
- project health
- risk alerts
- cross-project comparisons

## First recommended step

If we move now, the best return comes from:

1. task owners and dates
2. comments and history
3. blockers and impediments
4. milestones and roadmap
5. project health reporting

## Product rule

AI should create drafts and speed up decisions. Humans approve what is critical.
