# V2 Evolution Plan

The next product stage focuses on making Aligna feel like a real project-management platform.

## Main goal

Move from artifact-centric delivery to continuous project execution.

## First capabilities to add

- task owners
- due dates
- blockers and impediments
- comments and mentions
- milestones and roadmap
- project health overview

## Principle

The new stage should keep the current AI strength, but make the board and execution layer more useful every day.

## Suggested order

1. task metadata and ownership
2. comments and activity history
3. blockers and checklist visibility
4. milestones and roadmap
5. executive health metrics
